# Sass-Based Web Project

##  Overview

This project is a simple web application developed using **Sass (Syntactically Awesome Stylesheets)** to enhance CSS styling with better structure, reusability, and maintainability. It demonstrates how Sass features can be used to write clean and efficient styles for modern web development.

##  Features

* Use of variables for consistent styling
* Nesting for better code readability
* Reusable mixins and functions
* Modular SCSS structure
* Clean and responsive UI design

## Technologies Used

* HTML5
* CSS3
* Sass (SCSS)

##  Project Structure

```
project-folder/
│── index.html
│── css/
│   └── style.css
│── scss/
│   ├── _variables.scss
│   ├── _mixins.scss
│   ├── _base.scss
│   └── style.scss
```

##  Installation & Setup

1. Clone the repository:

```
git clone https://github.com/your-username/your-repo-name.git
```

2. Navigate to the project folder:

```
cd your-repo-name
```

3. Install Sass (if not installed):

```
npm install -g sass
```

4. Compile Sass to CSS:

```
sass scss/style.scss css/style.css
```

5. Run the project:

* Open `index.html` in your browser

##  Purpose

The purpose of this project is to understand and implement Sass features to improve CSS development workflow and create scalable stylesheets.
